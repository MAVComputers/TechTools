MAV Computers LLCTECHTOOLS

Start TechTools

For MAV Computers technicians. Run this on the PC you are working on.

  1. Right-click Start and open Terminal (Admin) or Windows PowerShell (Admin).
  2. Paste this command and press Enter:
irm techtools.mavcomputers.com/go | iex

The toolkit downloads, opens in its own window, and leaves nothing installed. Logs are saved to C:\ProgramData\MAVTechTools\Logs.
